# persian-rtl-fixer
اکستنشن کروم برای رفع بهم ریختگی در متنهایی که زبان فارسی و انگلیسی باهم ادغام هستن
# 🔤 اصلاح‌کننده خودکار نوشتار فارسی-انگلیسی

اکستنشن کروم برای رفع مشکل **به‌هم‌ریختگی حروف فارسی و انگلیسی** در مرورگر و پرامپت‌های هوش مصنوعی


## 🧠 مشکل چیست؟

وقتی با ابزارهای هوش مصنوعی مثل **ChatGPT**، **Gemini**، **Claude** یا حتی **Google Translate** کار می‌کنید، گاهی حروف فارسی و انگلیسی به‌طور نامنظم کنار هم قرار می‌گیرند و نوشتار نامفهوم می‌شود.
اکستنشن رو دانلود کنید
از حالت زیپ خارج  کنید
سه نقطه سمت راست در بالای صفحه کروم رو بزنید
Extensions رو کلیک کنید
manage extensions کلیک کنید
load unpacked کلیک کنید
بعد در مسیری که اکستنشن رو اکستراکت کردین پوشش رو انتخاب کنید 
اکستنشن فعال میشه
با زدن دکمه داخل اکستنش تمام صفحه از حالت بهم ریختگی به حالت تمیز تغییر می یابد
